# Feed

The Feed shows new work from sources you follow, newest first.

Code is not copy: `text-transform: uppercase` and `quietly` stay as written.

```css
.label { letter-spacing: .06em; text-transform: uppercase; }
```

Transcripts come from Whisper, the speech model. Meta's Muse app does this too.

Export as PDF, HTML or MDX through the API. See [the example](https://example.com/gold-seam).
