The source controls use Graphical Switch and Button. Suggestions use Graphical
Popover and Button, with Hugeicons free. Existing Feed layout and its older
Why this? control remain for KI-94 to replace. No fonts, theme values or icon
packs changed.

The screenshot test waits for the Graphical color mode and finishes finite
animations before capture. It checks discovery, original dates, lazy reads,
source switches, neighbour provenance and Follow resolving the site's feed.
No live source or model calls run in these tests.

The source controls were also inspected in a Volli Browser Tab, including a
switch click. The console had no errors. The native-process check reported
zero windows, no Dock registration and no foreground activation.
